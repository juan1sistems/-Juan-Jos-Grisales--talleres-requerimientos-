# Taller de Ingeniería de Requerimientos

## Validador de requisitos

Este proyecto contiene un programa en Python que realiza una validación básica de requisitos de software.

## Criterios evaluados

El programa analiza los siguientes criterios:

- Específico
- Medible
- Alcanzable
- Relevante
- Identificable
- Verificable

## Archivo principal

El archivo principal del proyecto es:

`validar_requisito.py`

## Funcionamiento

El programa solicita al usuario un identificador y un requisito.

Después realiza una validación básica y muestra si el requisito cumple con cada uno de los criterios definidos.
